WEB DELIVERY ADAPTATION
Keyboardia — https://github.com/adewale/keyboardia
Pinned source commit: 869d3f5095084003e1251aa3ebf2eab8f65f62fe
Uses the Virtuosity Drums mid-microphone recordings and provides selected
velocity/round-robin strikes encoded as AAC-LC (.m4a).

8bars mirrors the upstream AAC-LC files during the GitHub Pages build and
re-encodes them as 44.1 kHz, 96 kbps MP3. Visitors receive same-origin MP3s
via sample-map.js and Web Audio; .m4a is never directly used for playback.

The kit contains 60 distinct individually performed strikes: 16 kicks,
12 main snares, four quiet snare ghost takes, 16 closed hi-hats and
12 open hi-hats, across MIDI velocity layers 0–31 / 32–63 / 64–95 /
96–127 (main snares exclude 0–31; those are used as ghosts). No copyrighted breakbeat loops are copied.
